Control VISO

Arrastrá los estados desde la categoría VISO Deck a tus teclas. No se colocan automáticamente en el tablero.

En la app o web VISO: estrella → Elgato Stream Deck → «Descargar mi configuración para el plugin». Ese archivo vincula todos los controles de estados nuevos. No lo compartas: contiene tu acceso personal.

URL personalizada / compatibilidad con el plugin anterior

Las teclas anteriores conservan su URL. Renovar el token en VISO requiere importar una configuración nueva; las URLs antiguas dejan de funcionar.
