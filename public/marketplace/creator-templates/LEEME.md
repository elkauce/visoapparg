# Crear para VISO

Los ejemplos son referencias para preparar y documentar tus recursos. Los archivos JSON y ZIP se ofrecen como descargas: no ejecutan código dentro de VISO ni publican productos automáticamente.

1. Creá tu perfil en Marketplace > Espacio creador y solicitá su aprobación.
2. Prepará archivos originales o con licencia de distribución. Incluí instrucciones y requisitos de compatibilidad.
3. Creá una ficha, elegí la categoría, añadí una portada y una galería de imágenes o videos. Los videos pueden ser verticales u horizontales.
4. Indicá Gratis o un precio y su moneda. Para compra externa, conservá el enlace final de la tienda. Los enlaces afiliados se compran fuera de VISO.
5. Probá archivos, teclas o páginas en las versiones web y Android que declares compatibles.
6. Guardá el borrador, revisá su vista previa y envialo a revisión. Editá tus publicaciones desde Espacio creador.

Formatos: PNG, JPG, WebP, GIF, AVIF; MP4 y WebM; WAV, MP3, OGG, M4A y WebM de audio; ZIP y JSON según categoría. Hasta 60 MB por archivo y hasta 512 KB para JSON.

Usá imágenes cuadradas de 256 x 256 para teclas. Para fondos y demostraciones, conservá la proporción original: 1920 x 1080 horizontal o 1080 x 1920 vertical son recomendaciones, no requisitos. Probá el ajuste «Mostrar completa» del Display.

Los paquetes de plugins se descargan para su instalación en la aplicación compatible. VISO no instala ni ejecuta código arbitrario subido por un creador. Las páginas instalables usan las plantillas nativas disponibles en el formulario, con sus opciones validadas.

No incluyas contraseñas, tokens privados, datos de compradores ni configuraciones personales en recursos públicos. Documentá únicamente los permisos y conexiones que necesita el producto.
